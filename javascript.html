03 / Взаимодействие

Одно нажатие.
Понятный результат.

JavaScript помогает странице реагировать на действия. Разберем событие на примере кнопки.

Свяжите элемент и обработчик

Сначала найдите кнопку в документе, затем подпишитесь на событие click. Обработчик выполнится после нажатия. Подключайте файл со скриптом в конце body либо используйте атрибут defer.

const button = document.querySelector('#show-tip');
const message = document.querySelector('#tip');
button.addEventListener('click', () => {
  message.textContent = 'Измените пример под свою идею.';
});

Что считать успешным действием

Нажатие кнопки и правильное решение задания обозначают разные результаты. При проверке своего интерфейса учитывайте это: действие завершено, когда пользователь получил нужный результат, а не просто нажал кнопку.
