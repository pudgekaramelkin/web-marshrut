02 / Оформление

Дайте содержимому
пространство

Хорошее оформление помогает читать. Начните с ширины текста, межстрочного интервала и понятной иерархии.

Три базовые настройки

Ограничьте ширину основного блока, задайте удобный интервал между строками и добавьте поля по краям. Эти изменения уже делают длинный текст заметно удобнее.

body {
  margin: 0;
  font: 18px/1.6 system-ui, sans-serif;
}
main {
  max-width: 760px;
  margin: 0 auto;
  padding: 24px;
}

Сетка, которая умеет перестраиваться

Для карточек удобно использовать CSS Grid. Вместо жесткой ширины задайте минимальный размер, а браузер сам распределит доступное пространство.

.cards {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(240px, 1fr));
  gap: 20px;
}

Проверьте мобильный экран

Уменьшите окно браузера. Текст не должен обрезаться, кнопки должны оставаться доступными, а страница не должна требовать горизонтальной прокрутки. Длинный код допустимо прокручивать внутри отдельного блока.

Попробуйте сами

Добавьте к своей странице файл style.css. Настройте фон, цвет текста и отступы. Затем откройте ее на телефоне или в режиме мобильного устройства браузера.
