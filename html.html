01 / Структура

HTML объясняет,
что находится на странице

Заголовок должен быть заголовком, ссылка должна вести куда-то, а кнопка должна выполнять действие. Начните с этой простой логики.

Каркас документа

В head находятся название вкладки, кодировка и служебные настройки. Содержимое, которое видит посетитель, располагается внутри body. Атрибут lang помогает браузеру и программам чтения с экрана определить язык.

<!doctype html>
<html lang="ru">
  <head>
    <meta charset="utf-8">
    <title>Моя первая страница</title>
  </head>
  <body>
    <h1>Мой учебный проект</h1>
    <p>Здесь я собираю полезные заметки.</p>
  </body>
</html>

Выбирайте тег по смыслу

  • h1 обозначает основную тему, h2 выделяет раздел внутри нее.
  • nav объединяет основные навигационные ссылки.
  • main содержит основное содержимое страницы.
  • a с атрибутом href используется для переходов, button для действий.

Попробуйте сами

Создайте файл index.html. Добавьте заголовок о любимом занятии, два абзаца и ссылку на полезный ресурс. Откройте файл в браузере и проверьте переход по ссылке.

О данных и приватности

Тест и чек-лист работают в браузере. Сайт не запрашивает имя, почту или телефон. При подключении внешней аналитики сведения о посещении обрабатываются соответствующим сервисом. Текущее состояние подключения: подключены бесплатные счетчики LiveInternet и SberAds (Топ-100).
